### 基本语法

go声明的变量必须被使用，否则需要使用_来替代掉变量名，表明该变量不会被使用到

对于基本类型来讲，声明即初始化；对于引用类型，声明则初始化为nil

在 Golang 中只有同长度、同类型的数组才可视为“同一类型”，譬如 [4]int 和 [3]int 则会被视为不同的类型，这在参数传递的时候会造成编译错误

所有的基本类型都属于值类型，但是有几个类型比较特殊，表现出引用类型的特征，分别是 slice、map、channel、interface ，除赋值以外它们都可以当做引用类型来使用

go传入函数参数的是原对象的一个全新的 copy （有自己的内存地址）

Go 语言的函数参数传递，只有值传递，没有引用传递

int的长度和系统相关，32位机器是4字节，64位机器是8字节

#### new和make

new可以创建任意类型的变量赋零值，返回指针

make只用于创建并初始化引用类型的变量（切片、映射、通道），返回变量本身

#### 类型转换

go是强类型的静态类型语言，不支持隐式类型转换，常量（非const）转变量是允许的

整型默认是int类型，浮点型默认是float64类型

#### 包的可见性

go包的可见性规则是通过标识符的首字母大小写来控制的，如果一个函数、变量或类型名以大写字母开头，则它是导出的（exported），可以被其他包访问，如果以小写字母开头，则它是未导出的（unexported），只能在定义它的包内访问

#### 异常处理

所有可能出现异常的方法或者代码直接把错误当作第二个响应值进行返回，程序中对返回值进行判断，非空则进行处理

defer的作用是延迟执行某段代码，多个defer一开始用的链表存储后来用栈存储，都是先进后出

recover 的作用是捕捉 panic 抛出的错误并进行处理，需要联合 defer 来使用

函数return的时候会先赋值返回值，调用defer，然后return

### 原子操作

实际上，原子操作也可以通过加锁来实现，但是加锁操作涉及到**内核态**的上下文切换，会有比较大的性能消耗，而原子操作是在**用户态**完成的，性能更高，效率可能相差几倍

#### 互斥锁和原子操作的区别

* 互斥锁通常用于保护一段代码，只有一个 `goroutine` 可以访问这段代码，其他 `goroutine` 需要等待， 而原子操作通常用于保护一个变量，确保在并发环境下对变量的读写是安全的。
* 互斥锁是一种悲观锁，它认为并发访问是一种常态，所以会在访问前先加锁，而原子操作是一种乐观锁，它认为并发访问是一种特例，所以会先尝试进行操作，如果失败再进行重试。
* 互斥锁是一种重量级锁，它会涉及到内核态的上下文切换，性能消耗较大，而原子操作是一种轻量级锁，它是在用户态完成的，性能更高。
* 互斥锁有操作系统的调度器实现， 而原子操作则是有硬件提供的原子指令实现，无需加锁而实现并发安全。

#### 实现原理

原子操作的实现原理是通过 `CPU` 提供的原子指令来实现的，这些指令可以确保在执行过程中不会被中断，从而保证操作的原子性。由于大多数 `CPU` 的原子操作都是基于 `32` 位或 `64` 位的寄存器，所以 `Golang` 原子操作的范围也仅限于这两种类型。

### 协程

go协程，动态增长的栈，初始只有2KB，go调度器可以将协程映射到少量的内核线程运行

协程通信：通道、互斥锁、等待组

go协程不会阻塞，需要等待执行完成

```go
package main
import "sync"
func main() {
    var wg sync.WaitGroup
    wg.Add(1) //增加等待计数
    go func() {
        defer wg.Done() //减少等待计数
    }()
    wg.Wait()
}
```

#### GPM

**G（Goroutine）** ：表示一个 goroutine 的结构，存储程序计数器、栈指针、栈帧指针

**M（Machine）** ：表示一个操作系统线程，负责执行 goroutines

**P（Processor）** ：调度器，关联一个系统线程和一个就绪队列

Go协程有一个全局运行队列，联系几个系统线程，系统线程从全局运行队列中取出协程来运行，每个系统线程有自己的运行队列以时间轮转进行调度

#### 通道

channel分为有缓冲和无缓冲，内部封装了锁，读写通道是原子性的

**无缓冲通道** ：发送和接收都会阻塞，直到被接收或者通道有值

**有缓冲通道** ：发送会在缓冲区未满时不阻塞，在缓冲区满时阻塞；接收同上

### 切片

数组就是一片连续的内存， slice 是一个结构体，包含三个字段：长度、容量、底层数组指针，8+8+8字节

```go
type slice struct {
	array unsafe.Pointer // 元素指针
	len   int // 长度 
	cap   int // 容量
}
```

底层数组是可以被多个 slice 同时指向的，因此对一个 slice 的元素进行操作是有可能影响到其他 slice 的

```go
func main() {
    a:=[]int{1,2,3}
    b:=[]int{4,5,6}
    a=b
    b[1]=0
    fmt.Println(a) // [4 0 6]
}
```

#### 值接收者和指针接收者

如果实现了接收者是值类型的方法，会隐含地也实现了接收者是指针类型的方法，反之则没有

如果方法的接收者是值类型，无论调用者是对象还是对象指针，修改的都是对象的副本，不影响调用者

如果方法的接收者是指针类型，则调用者修改的是指针指向的对象本身

### map

删除不存在的key不抛异常

key支持能够==、!=运算的数据类型，具体来说是基本数据类型+字符串+数组（非切片）

map 不是线程安全的，在查找、赋值、遍历、删除的过程中都会检测写标志，一旦发现写标志置位（等于1），则直接 panic。赋值和删除函数在检测完写标志是复位之后，先将写标志位置位，才会进行之后的操作

### sync.map

并发安全的map，读写分离思想，用原子类型存储只读字典read，用互斥锁保护脏字典dirty，这两个字典各自维护一套key，但指向相同的value，用miss整型变量记录read未命中的次数，达到阈值同步dirty

### 垃圾回收

#### 三色标记法

白色对象：未访问的对象

灰色对象：正在访问的对象，子对象未访问完

黑色对象：访问过的对象，子对象访问完

一开始所有对象都是白色，将根对象（全局变量、栈上的局部变量、寄存器中的指针等）标记为灰色，访问子对象并标记灰色，如果某个对象的所有子对象访问完就标记为黑色，直到没有对象可以访问，清除所有的白色对象

按照时间间隔和堆增长大小进行

增量式回收，不一次性进行所有操作
